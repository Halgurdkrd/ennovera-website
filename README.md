# Ennovera — Website

Live site: **[ennovera.com](https://ennovera.com)**

The marketing and portfolio website for Ennovera, showcasing applied AI projects spanning prediction systems, medical imaging, plant intelligence, and Kurdish/Arabic NLP.

## What it does

- Presents an overview of AI projects and case studies (prediction systems, healthcare AI, agent-based automation, and more)
- Bilingual — full English and Sorani Kurdish support, including right-to-left (RTL) layout for Kurdish
- Serves as the public entry point linking to live products such as the AI football prediction platform

## Tech stack

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Deployment:** Vercel

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.
